# حلاقة الأمير

موقع لمحل حلاقة: الزبون يشوف الأسعار وصور الشغل، ويحجز دوره (التسريحة، اليوم، والساعة) من الموبايل.

## الصفحات

- **`index.html`**: الصفحة الرئيسية. فيها يافطة المحل، حالة المحل (مفتوح أو مسدود هسه)، لوحة الأسعار، صور الشغل ويا فلتر حسب التسريحة، العنوان وأوقات الدوام.
- **`booking.html`**: صفحة الحجز. الزبون يختار الخدمة واليوم والساعة ويكتب اسمه ورقمه، وبعدين ينفتح الواتساب ويا رسالة الحجز جاهزة تنرسل لرقم المحل.

الحجز يوصل للحلاق كرسالة واتساب، فما يحتاج سيرفر ولا قاعدة بيانات. الدور يتثبّت من يرد الحلاق على الزبون.
حجوزات الزبون تنحفظ بموبايله هو بس (تطلع تحت عنوان "حجوزاتك")، ويگدر يلغيها برسالة واتساب.

## شلون تعدّل المعلومات

كل شي بملف واحد: **`js/config.js`**

| الشي | وين |
| --- | --- |
| رقم الواتساب اللي توصله الحجوزات | `whatsapp` (مثال: `9647701234567`، بدون + وبدون صفر البداية) |
| رقم الاتصال | `phoneDisplay` |
| العنوان ورابط الخريطة | `address` و `mapUrl` |
| الانستغرام | `instagram` |
| أوقات الدوام | `hours` (الأرقام من 0 الأحد إلى 6 السبت، و `null` يعني عطلة) |
| الخدمات والأسعار والمدة | `services` |
| صور الشغل | `gallery` |

> **مهم:** رقم الواتساب الحالي `9647700000000` مجرد مثال. لازم تبدله برقم المحل الحقيقي قبل ما تنشر الموقع.

## صور الشغل

الصور الحالية بمجلد `images/gallery` رسومات مؤقتة. حتى تحط صور شغلك الحقيقية:

1. حط الصور (jpg أو webp، يفضّل بالطول وبحدود 1000 بكسل) بمجلد `images/gallery`.
2. بملف `js/config.js` بقائمة `gallery`، غيّر `src` لاسم الصورة، و `caption` لوصف قصير.
3. خلّي `style` نفس `id` الخدمة (مثل `fade` أو `beard`) حتى يشتغل الفلتر.

```js
{ src: "images/gallery/ali-fade.jpg", style: "fade", caption: "فيد عالي" },
```

## التجربة على جهازك

افتح `index.html` بالمتصفح مباشرة، أو شغّل سيرفر بسيط:

```sh
npx serve .
```

## النشر على GitHub Pages

1. بالمستودع على GitHub روح لـ **Settings ← Pages**.
2. بـ **Source** اختار الفرع (`main`) والمجلد `/ (root)`.
3. بعد دقيقة يطلع رابط الموقع.
